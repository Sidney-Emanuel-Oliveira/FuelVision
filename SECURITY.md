# Política de segurança

## Versões com suporte

O projeto educacional mantém somente o conteúdo atual da branch `main`. Não há
garantia de correções para commits antigos ou forks.

## Relatar uma vulnerabilidade

Não publique credenciais, dados sensíveis, exploração funcional ou detalhes que
facilitem abuso em uma issue pública.

Prefira o recurso **Private vulnerability reporting** do repositório no GitHub.
Se ele não estiver habilitado, contate o proprietário pelo perfil do GitHub para
combinar um canal privado antes de enviar os detalhes.

Inclua, quando possível:

- componente e versão afetados;
- condições necessárias para reproduzir;
- impacto observado;
- passos mínimos sem dados reais ou segredos;
- sugestão de correção, se houver.

O recebimento será confirmado quando o proprietário acessar o relato. Como este
é um projeto individual e educacional, não existe SLA formal de resposta.

## Escopo

São relevantes falhas no código, imagens, configuração Compose, API e exposição
indevida de dados do FuelVision. Problemas exclusivos do provedor, sistema
operacional ou Docker devem ser relatados também ao mantenedor correspondente.
